# AngryBirdsToSpace 游戏设计稿

> 状态：立项设计稿。编码：UTF-8，简体中文。
>
> 目标：在一个月内完成一款以 PCG 和物理为核心的第三人称 3D 小行星采集、建造与发射游戏；第一周完成中期评审可实际游玩的闭环。

## 1. 概念与终局

四只具有不同能力的小鸟被困在一颗程序化生成的小行星上。玩家操控鸟群拾取资源、建造逐级强化的弹弓、将同伴发射至环境障碍处，最终建成钢铁太空弹弓，让鸟群飞离星球。

```text
探索与拾取
-> 天然树枝简易弹弓
-> 发射棱喙砍树
-> 强化弹弓
-> 发射玄爪破岩采晶体
-> 钢铁太空弹弓
-> 飞离星球
```

本作不复刻既有弹弓游戏。鸟名、轮廓、动作、音效、任务叙事和美术资产均使用原创设计；核心是“在球面环境中弹射同伴解决采集与建造问题”。

最终发射必须是真实演出：四鸟就位、弹弓蓄力、鸟群被抛向天空、球面重力逐步淡出、镜头拉远，首次展示小行星悬浮在宇宙中。

## 2. 设计支柱

| 支柱 | 玩家感受 | 实现约束 |
| --- | --- | --- |
| 弹射是主动作 | 弹弓既解锁同伴能力，也是投送、移动与解题工具。 | 每次弹弓升级都必须打开新资源或新区域。 |
| 物理有后果 | 树会倒、石会碎、资源会滚、鸟会落地。 | 关键采集至少产生一次可见物理结果。 |
| PCG 决定路线 | 每颗星球的森林、岩区、晶体区、遗址关系不同。 | 固定 Seed 可复现，PCG 不只摆装饰。 |
| 低学习成本 | 玩家总能知道下一种稀缺资源和下一项建造。 | 仅三次核心升级，不做复杂科技树。 |
| 终局有反差 | 地表阶段明亮亲和，离开时才显露宇宙。 | 普通探索不刻意强调太空视觉。 |

## 3. 资源、建筑与主循环

### 3.1 资源

| 资源 | 初始分布 | 大量来源 | 用途 |
| --- | --- | --- | --- |
| 树枝 | 常见掉落 | 林地、倒木附近 | 工作台、简易弹弓、青翎发射点。 |
| 石料 | 常见掉落 | 岩区、破碎石块 | 建造、强化弹弓、熔炉。 |
| 木材 | 开局极少 | 棱喙砍树 | 强化弹弓、熔炉、发射平台。 |
| 晶体 | 开局极少 | 玄爪破固化石料 | 钢铁太空弹弓核心。 |

玩家在开局就应看到全部资源。树枝、石料较常见，木材、晶体稀少，从而让能力升级的价值一眼可见。

### 3.2 建造与配方

初版只有工作台、熔炉和弹弓。熔炉用于加工太空弹弓部件，不引入燃料、电网、运输带或完整自动化工厂。

| 阶段 | 建造 | 建议材料 | 结果 |
| --- | --- | --- | --- |
| 0 | 树枝 | 天然存在 | 可发射青翎。 |
| 1 | 工作台 | 树枝 + 石料 | 开启制作与建造。 |
| 2 | 简易弹弓 | 大量树枝 + 少量石料 | 可发射棱喙。 |
| 3 | 熔炉 | 石料 + 木材 | 可加工太空弹弓部件。 |
| 4 | 强化弹弓 | 大量木材 + 少量石料 | 可发射玄爪。 |
| 5 | 钢铁太空弹弓 | 熔炼部件 + 晶体 + 木材 | 解锁终局集体发射。 |

首轮试玩的目标通关时间为 10 至 15 分钟；具体数量在试玩后调整。

## 4. 鸟群、第三人称与弹射

### 4.1 鸟群

| 鸟 | 初始状态 | 能力 | 物理结果 | 玩法职责 |
| --- | --- | --- | --- | --- |
| 红鸟 `绯翼` | 开局主控 | 携带、建造 | 推拉小资源、摆放建筑。 | 基础行动入口。 |
| 蓝鸟 `青翎` | 开局同行 | 树枝弯折发射、侦察、拍照 | 高空短时滑翔。 | 更新探索地图。 |
| 黄鸟 `棱喙` | 简易弹弓后可用 | 凿击、砍树 | 树干倾倒、木材掉落。 | 解开木材瓶颈。 |
| 黑鸟 `玄爪` | 强化弹弓后可用 | 破碎固化石料 | 碎块、石料、晶体掉落。 | 解开晶体瓶颈。 |

所有鸟都有捡拾能力，都可作为主控。

### 4.2 控制规则

1. 第三人称相机控制当前主控鸟。
2. `Tab` 循环切换主控鸟；HUD 提供鸟头像按钮，可用鼠标直接切换。
3. 非主控鸟在球面切向目标点上跟随主控鸟，再受径向重力贴地。
4. 发射、砍树、破岩或距离过远时暂时脱队；动作结束或落地后归队。
5. 初版不建设全球 NavMesh。跟随采用球面方向追踪、简单避障与最大距离保护；卡住的鸟以短距离飞跃/回收至安全位置并播放落羽特效。

### 4.3 弹弓

- 接近弹弓后进入发射模式，选择已解锁鸟。该弹弓无法使用的鸟在选中时会弹出说明。
- 拖拽或摇杆决定球面切线方向与蓄力长度；只显示近距离抛物线预览。
- 发射鸟使用刚体初速度，并持续施加径向球面重力：

```text
GravityDirection = normalize(PlanetCenter - BirdWorldPosition)
Force = GravityDirection * Mass * GravityAcceleration
```

- 发射失败不会永久失去鸟；落地后可重新操控或自动归队。

## 5. 物理采集与建造

| 对象 | 交互 | 初版物理结果 |
| --- | --- | --- |
| 树枝、石料、木材、晶体 | 绯翼靠近拾取 | 小刚体可短暂滚动、被推开、吸附进拾取范围。 |
| 树木 | 棱喙连续凿击 | 树干倾倒、碰撞、掉落木材；数秒后转静态或销毁。 |
| 固化石料 | 玄爪蓄力冲击 | 破裂特效 + 最多 12 个碎块 + 石料/晶体掉落。 |
| 枝条发射点 | 青翎交互 | 枝条弯曲并提供固定方向的初速度。 |

建造只允许绯翼执行，且所有建造逻辑以 `CellTopo` 为唯一判定源：玩家选择目标 Cell 后，建筑固定落在该 Cell 的球面中心位置；连续地表只负责查询该点的最终渲染高度、碰撞和表现，不参与建造归属、合法性或相邻关系判定。建筑朝向采用主控鸟前向投影到目标 Cell 切平面的方向，局部向上方向为该 Cell 中心的径向方向。

建筑只能建在坡度平缓的 CellTopo 中心点。PCG 在生成 CellTopo 高度场后，为每个 Cell 预计算 `BuildSlope`（以该 Cell 及其邻居的逻辑高度值估计）；连续表面只将此高度场插值为最终可见高度。仅 `BuildSlope <= BuildableSlopeThreshold`、非河道/湖泊、未被资源或建筑占用的 Cell 可建造；预览直接显示目标 Cell 的可建、不可建原因。首版不做任意位置摆放、自由模块拼装或运行时整地。

建筑联动只使用 `Cell.NeighborCellIds`，不使用世界距离：熔炉必须位于工作台的相邻 Cell；钢铁太空弹弓必须位于发射遗址 Cell 或其相邻 Cell；普通和强化弹弓独立工作。每类建筑首版最多一座，并保持 Cell 占用互斥。该规则既形成紧凑基地，也保持球面任意位置的一致性。

物理边界：只有当前发射鸟、倒下树干、掉落资源、少量破碎石块使用真实刚体。草、远景树和普通岩石保持 HISM，禁止实现全地形破坏、大量同步倒树、复杂布料或持续燃烧。

## 6. PCG 小行星与地形

> Task 图驱动的区域分配、道路/河网约束、桥梁状态和生成后可达性验证见 [ABTSTaskGraphPCGDesign.md](ABTSTaskGraphPCGDesign.md)。本章只保留主设计约束。

### 6.1 拓扑与几何预算

| 层 | 规格 | 数量 | 职责 |
| --- | --- | ---: | --- |
| 逻辑/PCG | 正二十面体 `CellTopo Sub=5` | `10 * 4^5 + 2 = 10,242` Cell | 资源区、地块、资源查询、探索。 |
| 渲染 | 连续球面 `Sub=7` | `20 * 4^7 = 327,680` 三角形 | 低模地表、高度起伏、地面碰撞。 |
| 对应关系 | 渲染层高两级 | 平均约 `32` 三角形/Cell | 供逻辑 Cell 产生连续轮廓。 |

`Sub=7` 对 `Sub=5` 的平均映射是约 32 个渲染三角形/Cell。**CellTopo 永远是球面的逻辑源**：地块、资源、建筑、道路、水网、探索、可达性和任务验证均以 CellId、Cell 中心及 `NeighborCellIds` 表达；连续球面不拥有独立玩法状态，只负责按 CellTopo 数据生成高度、碰撞、材质和 HISM/Actor 表现。初版不要求运行时改变 Continuous Surface；资源变化通过独立 HISM/Actor 表现。

### 6.2 生成流程

```text
WorldSeed
-> fbm / Voronoi / 域扭曲生成低频资源大区
-> CellTopo Sub=5 标记资源倾向
-> 区块内 WFC 或确定性邻接规则生成具体地块
-> 在 CellTopo 图上生成河网、道路、桥址和区域路线
-> 由 Cell 地块、河网和低频场重算球面高度
-> Continuous Surface Sub=7
-> 由 CellTopo 数据驱动连续材质、HISM 草/树/岩石/资源、道路和水体表现
```

### 6.3 大区与地块

低频场至少生成起始平原、森林、岩区、晶体富集区和发射遗址周边。大区只记录资源倾向；区块内部再生成草地、疏林、密林、碎石坡、固化石料带、晶体露头等地块。

WFC 必须局部化：区块独立求解、最大回溯步数、确定性随机、失败时回退到邻居计数规则扩散。禁止对完整 10,242 个 Cell 做无上限的全局 WFC。

高度场原则：平原低起伏、林地柔和丘陵、岩区较高但低模清晰、固化石料带用局部岩丘表达、发射遗址与候选建造 Cell 保持平整。初版不追求高保真连绵山脉。

### 6.4 道路、水网与区域路线

道路和水网均是 `CellTopo` 图上的逻辑网络，而非材质绘制后再反查的效果。河段记录为有向相邻 Cell 边 `FromCellId -> ToCellId`，并带有汇流量、宽度等级、两岸 Cell 和可跨越状态；道路记录为相邻 CellId 序列。连续球面根据这些图数据绘制河道、水面、湿润带、道路、桥和浅滩，但不改变其逻辑拓扑。

河网沿由高度场导出的相邻 Cell 下游关系生成，要求无环、可汇流，并在终点形成小湖或湿地。首版按汇流量划分为细流、浅河、深河/湖泊：细流可直接通过；浅河只能从 `Ford`（浅滩）、`FallenLog`（倒木）或 `Bridge`（桥）边跨越；深河和湖泊不可步行跨越、不可建造。鸟落入水体时播放落水反馈并回收至最近可通行河岸 Cell，不造成永久失败。

河流不是纯惩罚：河岸/湿润带 Cell 提高树枝和可砍树密度，汇流处可提高石料或晶体露头概率，并可作为青翎侦察的醒目地标。关键浅河边必须预留桥址或定向可砍倒树：棱喙砍树获得木材后，绯翼可在桥址建造木桥，将该相邻 Cell 边的 `CrossingType` 切换为 `Bridge`，从而打开通向岩区或遗址的路线。首版不做任意倒树搭桥、游泳、浮力或动态水文。

道路按 Cell 邻接寻路串联起始区、工作台候选区、森林、桥址、岩区和发射遗址；道路提供队伍跟随和移动的优先走廊，但不做物流或速度数值系统。道路与深河相交时必须生成桥址，和浅河相交时必须生成浅滩、倒木或桥址。生成完成后必须在 CellTopo 图上验证主线：起始区 -> 工作台候选区 -> 可砍树目标 -> 可用桥址 -> 固化石料区 -> 发射遗址；除桥梁建造这一设计锁外，任何阶段不得因河网或道路生成而不可达。

### 6.5 材质、HISM 与资源

连续地表使用纯色或少量色块，不再依赖三平面 SDF 纹理/法线解释局部网格。SDF/Field Query 仅负责连续的密度、坡度、地块类型、距资源区距离等查询；细节由 HISM 草、树、岩石、树枝和晶体表现。

资源必须可复现：

```text
PlacementRandom = Hash(WorldSeed, CellId, ResourceType, LocalIndex)
```

| 对象 | 默认表示 | 交互时变化 |
| --- | --- | --- |
| 草、装饰石 | HISM，无碰撞或简易阻挡 | 不变。 |
| 可砍树 | HISM 外观 | 交互时替换为少量物理 Actor。 |
| 固化石料 | HISM 外观，Visibility 命中 | 破碎时生成碎块与掉落物。 |
| 资源掉落物 | Instanced/Actor 混合 | 拾取或计时清理。 |

## 7. 视觉、青翎小地图与终局

地表阶段使用正常日光、天空和环境光，重点是森林、岩区、资源和角色的清晰辨识。不要在此阶段用极暗背光、宇宙星空或强烈行星轮廓压过采集建造体验。

青翎是“物理侦察相机”：玩家在枝条发射点将其弹向高空，飞行期间短暂切入垂直向下的侦察镜头并拍照。拍照覆盖范围写入小地图纹理，显示已发现的资源区、建筑和发射遗址方向。落地后青翎归队，不做永久自由飞行。在该小地图中持续更新资源区等，并持续更新玩家所在位置，但只会通过玩家再次发射青翎来更新小地图的显示范围。

可复用现有项目的球面拓扑、World Seed、连续 Surface、高度采样、HISM、空间投影命中、LUT 高亮经验和相机绕球基础。

新玩法必须独立于旧回合制 Gameplay：新地图、新 GameMode、新 UI、新存档数据。旧棋子、阵营、回合、Cell 点击移动和 NPC 系统只保留在旧模式作技术备份。

## 11. 风险与性能预算

| 风险 | 原因 | 控制方案 |
| --- | --- | --- |
| 全局 WFC 卡顿 | 10,242 Cell 回溯规模过大。 | 局部求解、步数上限、规则扩散回退。 |
| Surface 重建慢 | Sub=7 有 327,680 三角形。 | 仅新局/显式重建；首版静态。 |
| 物理拖慢 | 多树倒下、碎块不回收。 | 活跃刚体不超过 50；破岩最多 12 块；睡眠与计时清理。 |
| HISM/Actor 爆量 | 所有资源都生成 Actor。 | 远景 HISM，靠近或交互再替换为 Actor。 |
| 球面跟随不稳定 | 全球 NavMesh 不适配。 | 球面切向追踪 + 距离阈值回收。 |
| 河网阻断主线 | 河道和道路随机生成使目标区域不可达。 | 将河道/道路/桥址全部表示为 CellTopo 边；生成后执行主线路径验证，失败则用同 Seed 派生重试或修复桥址。 |
| 首周范围失控 | 同时实现终局和最终美术。 | Day 4 前必须砍树与桥梁闭环，Day 5 前必须破岩闭环；道路和水网可降级为少量关键路径。 |

中期性能目标：进入固定 Seed 至可控状态不超过 20 秒；常规探索活跃刚体不超过 50；优先稳定 60 FPS。

## 12. 验收与暂不做

中期验收：玩家可完成“初始资源 -> 工作台 -> 仅消耗树枝和石料的简易弹弓 -> 砍树取木材 -> 在桥址建桥跨越浅河 -> 强化弹弓 -> 破岩取晶体 -> 熔炉加工 -> 钢铁太空弹弓 -> 四鸟集体发射”。所有地块、资源、道路、水网、建筑占用/联动和主线可达性均须可追溯到 CellTopo；连续球面只作为这些逻辑数据的可见与可碰撞表现。

暂不做：昼夜、天气、运行时 Continuous Surface 变形、洞穴、体素地形破坏、完整自动化工厂、电网、多人联网、大规模战斗/AI、无限宇宙或跨星球旅行。
