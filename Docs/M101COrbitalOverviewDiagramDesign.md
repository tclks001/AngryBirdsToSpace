## 1. 目标、边界与非目标

M10.1-C 在强化弹弓拉弓时提供一张圆形二维轨道全景图，让玩家在主视图只能看到起点、M10.1-B 只能看到终点附近时，仍能理解完整预测轨迹怎样绕过主星、卫星以及未来的局部力场。

本阶段必须做到：

1. 以整条 M6 预测轨迹拟合一个二维截面，不强制截面经过主星球心；
2. 将不共面的轨迹点正交投影到该截面；
3. 始终把弹弓发射点定向到图的左侧；
4. 以投影轨迹凸包决定平移和缩放，完整轨迹必须进入圆图安全边距，主星和卫星允许被裁切；
5. 主星只显示理想正球和世界绝对经纬网，不显示 HISM、SDF 地表、高程、道路、建筑、资源或侦察弧；
6. 卫星只显示理想圆形轮廓，不显示经纬网；
7. 使用原始三维轨迹与球体的深度关系判断遮挡：位于主星或卫星后方的轨迹画虚线，其余画实线；
8. 轨迹超过可调长度阈值后自动出现，不要求落点进入青翎侦察圆，也不要求 M10.1-B 正在显示。

本阶段不实现：

- 建筑目标、最佳路线、目标捕获圈或可行走廊；
- 失重区、旋风场本身的 Gameplay 与影响标签；未来力场接入时复用本图投影框架；
- 新的轨迹积分器、自动修正、自动寻的或实际飞行控制；
- 第二台全景 `SceneCapture`、全星球 RenderTarget 或地表资产采样。

## 2. HUD 位置与圆形安全区

圆图位于左上青翎侦察圆正下方、底部物品 HUD 左侧的空白区域。它在 `AABTSM10ScoutMapHUD::DrawHUD()` 中先于父级物品 HUD 绘制，因此背包模态界面仍可自然覆盖它。

```text
┌─────────────────────────────────────────────────────────────────┐
│  ╭──── 青翎侦察圆 ────╮       [M10.1-B 远端落点画中画]          │
│  │ 地形 / 鸟 / 标记   │                                          │
│  ╰────────────────────╯                                          │
│  ╭── M10.1-C 轨道全景 ─╮                                        │
│  │  发射点 ●──轨迹──X  │           弹弓主视图                    │
│  │  经纬主星 / 卫星    │                                        │
│  ╰────────────────────╯                                          │
│                          [BAG][物品栏……]                           │
└─────────────────────────────────────────────────────────────────┘
```

布局规则：

- 左边缘与青翎侦察圆使用相同 `TopLeftMarginPx`；
- 顶边为 `TopLeftMarginPx + MapDiameterPx + OrbitalDiagramScoutMapGapPx`；
- 默认直径 `250 px`；
- 视口不足时缩小圆图，底部至少为物品栏预留 `OrbitalDiagramBottomReservedPx`；
- 视口无法容纳最小直径时不绘制，不能越界或覆盖弹弓操作区；
- 所有图元都裁剪在圆形内容边界内。

## 3. 只读数据流与职责

```text
M6 Pulling 同源预测
  FABTSM6TrajectoryPreview
    WorldPoints / InitialWorldLocation / InitialWorldVelocity
    PredictedPathLengthCM / PrimarySurfaceLandingWorld
                │
                ▼
M10 ScoutMapSystem（只读转交 + 主星引用）
                │
                ▼
M10 ScoutMapSystem（TG_PostPhysics）
  拟合平面 → 正交投影 → 凸包构图
  主星/卫星理想球投影 → 三维深度遮挡 → 屏幕无关快照
                │
                ▼
M10 HUD
  像素缩放 → 圆形线段裁剪 → Canvas 绘制
```

- M6 继续拥有唯一预测积分；
- M10 世界系统在 M6 tick 之后读取快照，枚举 M9 卫星，并缓存屏幕无关的拟合、投影、经纬网与遮挡线段；
- HUD 不访问 Planet/Satellite Actor，只读取缓存快照并根据当前分辨率缩放；
- 所有图元是 `Canvas` 二维绘制，不创建 UObject、材质实例或 RenderTarget。

## 4. 整条轨迹的最佳拟合平面

为避免积分步长较密的局部被重复加权，先按相邻轨迹段长度给每个点分配弧长权重 `wi`，再计算加权质心：

```text
C = sum(wi * Pi) / sum(wi)
```

再计算三维加权协方差矩阵：

```text
Cov = sum(wi * (Pi - C) * transpose(Pi - C))
```

`Cov` 最小特征值对应的单位特征向量为拟合平面法线 `N`。这等价于最小化所有轨迹点到平面的平方距离：

```text
min sum(dot(Pi - C, N)^2), |N| = 1
```

实现使用固定次数的三阶对称 Jacobi 迭代，不分配大型矩阵，也不依赖编辑器模块。

若中间特征值相对最大特征值过小，轨迹近似直线；若最小与中间特征值间隙过小，最佳法线不唯一。两种情况都不采用不稳定的 PCA 法线，而按以下顺序回退：

1. 有历史截面时，将上一帧法线投影到与当前起终点弦垂直的平面；
2. 从发射点到后续点中寻找离起终点连线最远的点，以三点叉积建平面；
3. 使用主星径向与 `InitialWorldVelocity` 的叉积；
4. 使用世界 `Up / Forward / Right` 中与轨迹主方向最不平行的轴。

平面法线具有正负二义性。新会话首帧以世界 `Up`，再以世界 `Forward / Right` 建立确定性屏幕上方；后续帧优先让新二维纵轴与上一帧纵轴同向。正常 PCA 法线还先与上一帧法线同号，不做只收敛一次的低通插值。这样微调不会因世界参考轴跨阈值而整图翻转，也不会同步颠倒前后遮挡。

## 5. 弹弓左置与正交投影

在拟合平面上先建立任意正交基。若上一帧水平轴仍能把发射点作为轨迹凸包的左侧支撑点，则继续复用；否则从凸包中找到发射点，并使用相邻两条边的向内角平分方向。近平面退化或发射点不再是凸包顶点时，回退为发射点指向拟合质心/终点的方向。最后比较该轴上相对发射点的最小、最大投影，必要时整体翻转水平轴，保证发射点至少位于最终水平包围盒中心的左侧。

因此普通单圈以内轨迹满足：

```text
ScreenX(Launch) <= ScreenX(Pi)
```

若轨迹自身环绕并包围发射点，几何上不存在让发射点成为绝对最左点的无畸变投影；此时仍保证发射点位于图的左半侧，不拉伸或扭曲轨迹。

任意世界点 `P` 正交投影为：

```text
PlaneX = dot(P - C, AxisX)
PlaneY = dot(P - C, AxisY)
Depth  = dot(P - C, PlaneNormal)
```

所有不在拟合平面上的轨迹点只丢弃 `Depth` 分量；二维位置不按主星球心、落点或卫星重新修正。

## 6. 凸包、自适应缩放与圆形裁剪

1. 对全部二维轨迹点计算单调链凸包；
2. 以凸包包围盒中心作为构图中心；
3. 计算凸包顶点到构图中心的最大距离；
4. 若把真实地表落点径向归一到理想基础球后的 `X` 位于该半径外，只扩张半径以容纳标记，不改变构图中心；
5. 使用圆图内半径减去 `OrbitalDiagramContentPaddingPx` 得到缩放；
6. 所有完整轨迹点和有效落点标记必须位于该安全半径内。

主星和卫星不参与缩放求解。这样轨迹跨度变大时图会自动拉远，轨迹跨度变小时图会拉近；不会为了强行容纳完整主星而把轨迹压缩成难以辨认的一小段。

圆形裁剪在线段层执行。轨迹、球体轮廓和经纬网投影线段与圆形内容边界求交，仅绘制落在圆内的部分。

## 7. 理想主星、绝对经纬网与卫星

主星只使用：

```text
Center = PrimaryPlanet.GetPlanetCenterWorld()
Radius = PrimaryPlanet.GetPlanetRadiusCM()
```

世界绝对经纬基准固定为：

- 北极轴：世界 `+Z`；
- 本初子午线：世界 `+X`；
- 东经增加方向：从 `+X` 朝 `+Y`。

纬线由固定纬度和变化经度采样，子午线由固定经度和变化纬度采样。每个三维网格点再正交投影进拟合平面；玩家改变发射方向时，截面和二维基改变，因此脚下经纬网会在图中移动，帮助辨认三维偏转关系。经纬线是世界绝对坐标，不跟随弹弓重置原点。

主星后半球经纬线使用低透明虚线，前半球使用较亮实线；不显示经纬度数字。主星轮廓始终表示基础正球，不读取：

- M3 连续 SDF 高程；
- Forest/Rock 等 HISM；
- 道路、河流、桥梁；
- 建筑、物品和鸟；
- M10 侦察覆盖。

卫星只读取中心和基础半径，绘制理想圆形轮廓，不画经纬网。只有其投影圆与当前圆形视口相交时才产生图元。

## 8. 球体遮挡与轨迹实虚线

遮挡不能通过“二维点落入圆形”直接判断，因为二维重叠无法区分轨迹位于球体前方还是后方。

对球体中心 `B`、半径 `R` 和原始三维轨迹点 `P`：

```text
Q     = P - B
Side  = dot(Q, PlaneNormal)
RadialSquared = |Q|² - Side²
FrontDepth = sqrt(R² - RadialSquared)
Hidden = RadialSquared < R²
         && Side < FrontDepth - DepthEpsilon
```

满足 `Hidden` 表示从拟合平面法线正向观察时，该点位于球体投影轮廓内且在球体前表面之后。任一主星或卫星遮挡即判为隐藏。

每条原始轨迹段同时求它与各球体“投影圆柱边界”和“三维球面边界”的参数根，合并、排序并去重这些切分点，再对每个小区间的中点执行射线—球体遮挡分类。这样即使一条长线段的两个端点状态相同，中间短暂穿过卫星投影也不会漏掉虚线段。切线、极短区间和球面端点使用小容差，避免连续微调时一帧实线、一帧虚线。

可见段使用浅蓝白实线；球后段使用同色低透明虚线。虚线只表达空间遮挡，不代表预测不确定性或侦察范围。

## 9. 显示资格与长度滞回

首次显示同时满足基础资格，并命中长度或主视图兜底：

1. 已存在一张有效青翎侦察图；
2. 当前为强化弹弓 `Pulling` 的有效 M6 预测；
3. `WorldPoints.Num() >= 2`；
4. `PredictedPathLengthCM >= OrbitalDiagramMinPathLengthCM`，或有效主星落点已经离开主视图 `OrbitalDiagramViewportInsetRatio` 安全框/被主星基础球遮挡。

已显示后，长度门槛降为：

```text
PredictedPathLengthCM
  < OrbitalDiagramMinPathLengthCM
    - OrbitalDiagramPathLengthHysteresisCM
```

当路径低于该门槛，且有效落点也已经回到主视图安全框内并未被主星遮挡时才隐藏。松开发射、预测失效、离开强化弹弓或关闭功能时立即隐藏，不等待滞回。

默认 `OrbitalDiagramMinPathLengthCM = 2500 cm`。默认主星半径为 `10000 cm`，发射镜头距弹弓 `1150 cm`、径向抬高约 `1150 sin(18°) ≈ 355 cm`，基础球几何地平线弧距约 `2600 cm`，因此首版阈值略早于地平线。固定长度无法覆盖所有 FOV、窗口比例和相机配置，所以实现同时检查落点是否离开 6% 内缩安全框以及 Camera→Landing 是否被主星基础球遮挡；该兜底才是“落点离开主视距前出现”的最终保证。关卡更改主星尺度或发射镜头时仍应在 `AABTSM10GameMode` 中重新标定长度阈值。

该资格不依赖：

- 预测落点是否位于侦察圆；
- 是否存在有效主星落点；
- M10.1-B 画中画是否显示；
- 主星是否能完整进入轨道图。

## 12. 性能预算

- 每帧只消费当前一条最多 512 点的预测；当前默认强化预测为 160 点；
- 平面拟合与投影为 `O(N)`，凸包为 `O(N log N)`；初始位置、初速度、点数和路径长度未变化时复用缓存；
- 经纬网使用固定角度间隔和固定采样上限，不随主星网格细分增加；
- Canvas 线段预算建议不超过 700 段/帧；
- 不增加 SceneCapture、RenderTarget、纹理、材质采样器或显存常驻；
- 目标预算：常规 160 点预测下 GameThread 增量低于 `0.5 ms`，GPU 增量仅为低分辨率 HUD 线段合成。

若后续性能分析显示 Canvas 逐线提交成为瓶颈，可将同类线段批量转为 Slate/自定义顶点缓冲，但不能改变投影和遮挡契约。

- [ ] 修改公开参数后无需修改 C++ 即可重新标定阈值、尺寸、间距和虚线。

## 14. 排错表

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 圆图始终不出现 | 未完成青翎侦察，或仍复用了 M10.1-B“落点必须在侦察圈内”的资格 | C 使用“有效侦察图 + 强化 Pulling + 有效预测 +（路径长度或主视图兜底）”，但不要求落点进入侦察圆 |
| 弹弓突然跑到图右侧 | 直接使用 PCA 任意特征向量作为水平轴 | 在拟合平面内重新搜索以发射点为左侧支撑点的水平轴 |
| 拉弓时整图上下翻转 | 平面法线每帧采用任意正负号，或最小两个特征值近似相等 | 首帧用世界轴定向，后续沿用上一纵轴；特征间隙不足时走稳定回退 |
| 轨迹变长后末段被裁掉 | 缩放使用主星半径或固定世界范围 | 以完整投影轨迹凸包计算构图中心与缩放 |
| 轨迹清楚但主星太小 | 强制把完整主星纳入构图 | 主星不参与缩放，允许被圆形视口裁切 |
| 经纬网固定在弹弓脚下 | 经纬线以弹弓局部轴生成 | 使用世界 `+Z/+X/+Y` 生成绝对经纬点，再投影 |
| 球体前方轨迹也变虚线 | 只检查二维点是否落在球圆内 | 比较原始三维轨迹深度和球体前表面深度 |
| 球体切线处实虚线闪烁 | 深度比较没有容差，或只比较整段端点 | 求投影圆柱/三维球面交点后分区间分类，并过滤极短切分 |
| 经纬线或轨迹画出圆框 | 只缩放轨迹，未裁剪其他图元 | 所有线段统一通过圆形线段裁剪 |
| 帧率下降 | 经纬采样随球面细分或每帧创建渲染资源 | 固定网格角步长；仅做 Canvas 数据绘制，不创建资源 |
