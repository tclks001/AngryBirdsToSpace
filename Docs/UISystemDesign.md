# AngryBirdsToSpace UI 系统设计

> 文档定位：维护整个项目的玩家可见 UI 规则与信息层级，不记录某个里程碑的 C++ 文件、类拆分或具体工程落地。当前覆盖 M4 小队头像 HUD、M5 物品栏/背包/加工界面与 M10 青翎侦察小地图。
>
> 导航：[主设计稿](AngryBirdsToSpaceGameDesign.md) · [M4 鸟群与头像 HUD 落地](M4BirdPartyImplementationDesign.md) · [M5 背包/加工落地](M5InventoryCraftingImplementationDesign.md) · [M5.1 手持栏与世界物品](M51WorldItemsPlacementSlingshotDesign.md) · [M10 青翎侦察小地图](M10ScoutMinimapDesign.md)

## 1. UI 总原则

UI 应优先回答四个问题：当前控制谁、拥有什么、现在能做什么、为什么不能做。常驻信息保持轻量，复杂操作进入模态界面；所有关键状态不能只依赖颜色表达，还需要文字、数量或轮廓提示。

当前没有正式图标资源时，库存、配方等文字型条目以稳定的 ASCII 英文名称回退，避免 UE 默认 Canvas 字体缺少中文字形而显示方框；头像与小地图标记使用具有固定语义的纯色圆形回退。中文显示名仍保留在数据层。未来接入中文字体与纹理时不改变布局、点击热区、排序和信息语义。

## 2. 常驻 HUD 层级

### 2.1 小队头像

- 屏幕右侧固定显示红、蓝、黄、黑四个圆形头像。
- 顺序永不因主控切换而改变，避免玩家重新寻找角色位置。
- 当前主控使用外圈高亮；头像纹理缺失时使用对应纯色。
- 点击头像切换对应鸟，Tab 按固定顺序循环切换。
- 加工界面开启时头像仍可见，但模态界面优先接收点击，不允许在制作数量确认过程中误切换角色。

### 2.2 物品栏快捷栏

- 屏幕底部居中排列固定数量的格子。
- 物品第一次获得时，优先填入最左侧空格；已有物品只叠加数量。
- 物品数量降到零后腾出快捷栏位置，之后获得的新物品填入该空位。
- 快捷栏只展示共享背包的一部分，不保存独立副本；四鸟切换不会改变内容。
- 图标缺失时显示物品名称字符串，右下角显示数量。
- M5 基础版点击快捷栏可打开背包；M5.1 的现行规则由下段覆盖：已有物品格改为手持，空格才打开背包。

M5.1 起，快捷栏左侧增加独立 `BAG` 入口，右侧增加独立 `HELD` 手持格：点击已有快捷栏物品改为手持该物品；点击空格、BAG 或按 K 才打开背包。HELD 显示当前手持物和总库存数量，点击 HELD 清空手持，不丢弃物品。

### 2.3 青翎侦察小地图

- 初始不显示。只有青翎完成 Twig 弹弓发射、稳定落地并完整归队后，才在屏幕左上角揭示圆形小地图。
- 地图以该次真实落点为中心，范围和北向在揭示时固化；之后角色移动、相机旋转和主控切换都不会让地图平移或旋转。
- 当前只保留一张侦察圆盘。青翎再次完成侦察时，以新落点替换旧地图，不在本阶段累积战争迷雾并集。
- 底图显示与球面地表同源的 SDF 地形、连续道路和连续河流，忽略地形高度与透视遮挡。
- 树、石头和建筑使用环境标记；Chaos 位移和破坏会定时刷新。建筑标记表示存活模块质心，模块全部摧毁后消失。
- 四只鸟使用头像表示并逐帧更新；头像纹理缺失时沿用右侧小队 HUD 的红、蓝、黄、黑纯色圆形。
- 位于圆盘范围外的对象直接隐藏，不吸附到边缘，也不显示方向箭头。
- 小地图不响应点击，不承担传送、放置或导航输入，因此不会抢占世界左键。
- 背包/加工界面是更高优先级的模态信息层，打开时覆盖小地图；关闭后地图恢复可见。

详细投影、数据更新、编辑器参数与验收见 [M10 青翎侦察小地图](M10ScoutMinimapDesign.md)。

## 3. 背包与加工界面

背包和加工界面使用同一张模态面板。打开后角色移动和相机 Orbit 输入暂停，鼠标用于 UI；关闭后恢复游戏输入。

### 3.1 左侧：共享背包

- 显示队伍当前拥有的全部非零物品。
- 顺序沿用首次获得顺序，数量变化不引起跳位。
- 每行显示图标/名称和总数量。
- 物品增多时使用滚动区域，而不是缩小字体；鼠标滚轮滚动左侧列表，右侧滚动条显示当前位置。
- 点击背包中的任一非零物品，与点击快捷栏已有物品具有相同语义：将其设为手持物品；当前手持行以选中态高亮。

### 3.2 右侧：配方列表

配方按以下稳定分组从上到下排列：

1. 材料、主控鸟和站点均满足，可立即制作；
2. 站点满足但材料不足；
3. 因缺少附近工作台或熔炉而锁定。

红鸟资格是全局加工权限：主控不是红鸟时，所有行额外显示 `RED BIRD`，但仍保持材料/站点分组，让玩家可以预先规划。

每个配方行必须包含：

- 产物名称或图标；
- 每种材料的 `已有数量/所需数量`；
- 不足数量使用红色；
- 缺少的工作台或熔炉使用红色文字和工具图标位置；
- Hover 提示完整失败原因；
- 点击不可制作项时短暂加强红色高亮，提供明确反馈。

### 3.3 制作数量弹窗

点击可制作配方后弹出居中确认面板，初始数量为 1。四个调整按钮固定为：

| 按钮 | 行为 |
| --- | --- |
| `--` | 减少 10 |
| `-` | 减少 1 |
| `+` | 增加 1 |
| `++` | 增加 10 |

调整结果限制在 `0..最大可制作量`。数量为 0 时确认按钮不可执行；确认成功后扣除全部材料、增加产物并关闭弹窗，背包与配方状态立即刷新。

## 4. 加工权限与环境提示

- 只有红鸟作为当前主控时才能执行加工。
- 徒手配方不要求站点。
- 工作台配方要求当前主控位于工作台使用范围内。
- 熔炉配方要求当前主控位于熔炉使用范围内。
- 点击世界中的工作台或熔炉可以打开界面，但距离不满足时只打开查看状态，不绕过距离与红鸟判定。
- 后续建筑逻辑必须由 CellTopo 提供放置和相邻关系；UI 只显示玩法系统给出的可用性，不用渲染距离反推逻辑。

## 5. 视觉状态

| 状态 | 建议表现 |
| --- | --- |
| 可制作 | 深绿色或中性高亮，文字清晰 |
| 材料不足 | 暗红底，不足数量鲜红 |
| 缺少站点 | 放在列表末尾，红色工具名称/图标 |
| 非红鸟主控 | 顶部全局红色说明，每行附加 `RED BIRD` |
| 点击无效 | 约 0.5 秒增强红色闪烁 |
| 当前主控头像 | 黄色外圈，不移动头像位置 |
| 侦察尚未完成 | 左上角不预留空地图，不提前泄露目标 |
| 侦察地图已揭示 | 浅色圆形边框、固定朝向、底部 `SCOUT MAP` 标识 |
| 地图图标资源缺失 | 树/石/建筑分别回退为绿/灰/橙色圆点，鸟回退为鸟种纯色 |
| 对象移出侦察范围或被摧毁 | 标记隐藏，不停留在旧位置、不吸附圆盘边缘 |

正式美术阶段可替换色板、边框和图标，但不得依赖复杂动画隐藏关键数值。

## 6. 输入约定

| 输入 | 作用 |
| --- | --- |
| 左键点击快捷栏 | 打开背包/加工界面 |
| K | 开关背包/加工界面 |
| 左键点击工作台/熔炉 | 打开界面并刷新附近站点条件 |
| X/关闭按钮 | 关闭界面 |
| Tab/头像 | 正常游戏时切换鸟；模态制作过程中不响应 |
| RMB 拖拽 | 仅界面关闭时控制 Orbit Camera |

## 7. 后续扩展约束

- M5.1 接入拾取与放置后，只调用共享库存增减和站点查询，不重写 UI 排序。
- 正式图标作为表现字段接入；字符串回退永久保留，用于缺资源和调试。
- 手柄支持应增加焦点导航，但不能改变列表分组和制作数量语义。
- 物品栏未来若引入选中槽，选中态与“打开加工界面”点击热区必须分离，避免一次点击同时使用物品。
- 侦察地图只能显示 Gameplay 系统已经确认的数据，不得从屏幕颜色、碰撞截图或最近六边形 Cell 反推地形与道路归属。
- 小地图若扩展为多次侦察并集，必须保留每次球面圆盘的中心、半径和参考方向；不能把旧图标直接复制到新圆盘坐标。
- 未来增加地图交互前，必须显式设计独立点击模式；不能直接给当前只读地图增加覆盖世界输入的 HUD HitBox。
